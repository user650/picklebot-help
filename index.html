Bring a friend

Anyone in the group can add or remove a guest. A first name is enough; a full name helps avoid confusion.

Add a guest

Picklebot add guest Steve SmithPicklebot add Steve to Monday eventPicklebot add Mary on Oct 23

The word guest is optional. If there’s more than one event, PickleBot will ask you to choose.

Remove a guest

Picklebot remove guest Steve SmithPicklebot delete Steve from MondayPicklebot remove Mary from 10/23

Remove and delete mean the same thing. If several guests share a first name, repeat the command with the full name.

Your own RSVP: use the GroupMe event’s RSVP buttons. Guest commands manage the additional guest list; they don’t change a member’s GroupMe RSVP. Add/remove confirmations show the updated roster.

PickleBot keeps an eye on it

Roster updates

RSVP changes trigger an updated roster for that event. A new event triggers the full upcoming-event list. Updates may take about a minute.

The evening before

Recruiting reminders run at 6 PM, 8 PM, and 9:30 PM in the event’s local timezone, unless the group already fills complete courts.

At the final check, fewer than four players brings a cancellation recommendation. An organizer decides; PickleBot doesn’t cancel automatically.
